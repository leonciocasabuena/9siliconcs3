## 1. What is duck typing, as explained in the video?
According to the video, duck typing is an alternative way of implementing polymorphism in object-oriented programming besides inheritance. Duck typing is a programming concept in which an object's ability to do a task relies on  whether it possesses the required methods and properties, rather than its actual class or explicit inheritance from such.

## 2. What did the Car class need to have so it could work inside the same loop as Dog and Cat, even if it does not inherit from the Animal class?
The car only had to have an identical method named speak() in order to work inside the same loop as the classes Dog and Cat even if it does become a child class of the superclass Animal.
